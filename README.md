# Portal de Postulantes

Portal web para publicar cargos y recibir información de postulantes.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS 4
- Phosphor Icons
- Preparado para Vercel

La estructura y dependencias siguen como referencia el proyecto `jc_money`.

## Estado actual

- Listado de cargos en la página principal.
- Selección de cargo.
- Formulario de datos personales.
- Educación.
- Experiencia profesional.
- Validaciones básicas del navegador.
- Confirmación de postulación en UI.
- Sin persistencia en BDD por ahora.

## Desarrollo local

```bash
npm install
npm run dev
```
